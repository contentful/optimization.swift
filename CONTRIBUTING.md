# Contributing

## Generated distribution repository

This repository is generated by the release process in
[`contentful/optimization`](https://github.com/contentful/optimization) and is not intended for
direct feature or bug-fix contributions. The authoritative Swift source lives under
[`packages/ios/ContentfulOptimization`](https://github.com/contentful/optimization/tree/main/packages/ios/ContentfulOptimization)
in that repository.

Open issues and pull requests against `contentful/optimization`. Changes made only here may be
overwritten by a later release. Do not manually copy upstream implementation changes into this
distribution repository.

## Exceptional repository maintenance

Direct changes should be limited to rare distribution-repository maintenance coordinated with the
maintainers, such as repairing release metadata or repository-level automation. Before making such
a change, confirm that it cannot be made in the authoritative source or release workflow instead.

## Setup and validation

For an approved direct maintenance change, run the applicable package checks:

- `swift package resolve`
- `swift build`
- `swift test`

Do not publish a release or regenerate package contents manually. Releases are produced by the
workflow in `contentful/optimization`.

## Review notes

Explain why the change must be made directly in this generated repository, identify the maintainer
who coordinated it, and record the validation performed. Never commit credentials, local
environment files, or service tokens.
